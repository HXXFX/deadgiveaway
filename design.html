Open this over http

This page is drawn by the game's own code, and browsers refuse to load ES modules from a file:// path — which is what you have if the address bar starts D:/ instead of 127.0.0.1. The game itself will not open from disk either, for exactly the same reason.

Run Open.bat in the project folder: the game opens itself, and the design sheet is one click away under Info. Or run Open.bat --design to come straight here.
